# XDocuments Manager 使用说明

版本：0.1.11  
适用系统：Windows、macOS

> 截图使用演示资料和测试状态；其中的资料夹名称、文件名、日志与更新版本仅用于说明界面，不代表真实用户数据或当前 GitHub Release。

XDocuments Manager 用于管理分散在本地磁盘和 SMB 共享目录中的 PDF。添加资料夹后，程序建立本地索引；文件仍保留在原位置。

## 1. 首次启动

首次启动会显示初始化阶段。数据库、搜索索引和搜索服务准备期间，窗口会显示加载动画和当前阶段。初始化完成后进入文件页。启动时也可以打开运行日志查看诊断信息。

RapidOCR 是默认 OCR 引擎。首次使用时，程序会在应用数据目录准备独立运行环境；过程可能需要一些时间。索引和本机 OCR 默认在本机处理文件内容。配置 MinerU 外部服务时，所选文件会发送至该服务。

![启动后的文件工作区](screenshots/01-文件工作区.png)

## 2. 添加资料夹并建立索引

1. 在左侧导航选择“资料夹”，然后点击“添加资料夹”。也可以点击导航栏“已索引资料夹”旁的加号。
2. 选择包含 PDF 的本地目录，或输入/选择可访问的 SMB 共享目录。
3. 确认添加后，程序开始增量索引。首次索引会读取目录并处理 PDF；后续扫描会比较文件大小和修改时间，只重新处理新增或变更的文件。
4. 左侧资料夹列表可在多个资料库间切换。任务中心显示索引进度；多资料夹任务分别显示状态。

需要重新计算全部文件索引时，在文件页工具栏使用“完整重建索引”。此操作会重新处理该资料夹的全部 PDF。

![资料夹管理](screenshots/02-资料夹管理.png)

## 3. 浏览文件和预览 PDF

在左侧选择资料夹即可浏览已索引文件。文件表格支持排序和分页；选择文件后可在内置 PDF 阅读器中预览。点击表头可切换排序方向。文件原件不会被移动。

![文件列表](screenshots/03-文件浏览.png)

## 4. 搜索

1. 选择左侧“搜索”。
2. 输入关键词并提交。搜索覆盖已索引资料库；使用筛选项缩小结果范围。
3. 查看结果中的文件名、匹配片段和页码信息，选择结果打开 PDF 预览。
4. 可在设置中配置 OpenAI 兼容模型进行可选查询词扩展。该功能向模型发送查询词，不发送 PDF 正文；不开启时仍可使用常规搜索。

搜索使用内置 Elasticsearch；服务不可用时程序可使用嵌入式 Tantivy 搜索后端。

![搜索结果](screenshots/04-搜索.png)

## 5. OCR 识别

在“OCR”页面选择识别引擎和语言，然后选择待处理文件并提交任务。也可将所有待处理文件加入队列。已完成 OCR 的文件不会在普通增量处理中重复识别；文件内容发生变化后会重新进入待处理范围。

- **RapidOCR**：应用管理的默认引擎。可选择自动设备或 CPU，并设置最大并发数；上限为 256，默认值较低以控制资源占用。
- **Windows OCR**：使用 Windows 提供的本机识别能力。
- **PaddleOCR**：应用管理的替代引擎，可设置设备模式。
- **MinerU**：可选的外部服务，需要自行配置服务地址；提交后所选文件会发送至该服务。

任务中心显示任务排队、处理中、完成或失败状态。OCR 输出目录和可用状态可在 OCR 页面查看。

![OCR 页面](screenshots/05-OCR.png)

## 6. 设置、更新和日志

设置页可调整界面语言、主题、搜索模型、OCR 运行选项，并查看搜索后端状态和应用版本。

程序启动后会自动查询 GitHub 最新 Release。发现新版本时，更新可在后台下载；下载完成后不会自动替换或重启程序。进入设置中的更新区域，点击“重启并安装”才会应用已下载版本。网络不可用时可稍后在更新区域重新检查。

![设置与应用更新](screenshots/06-设置与更新.png)

点击工具栏“运行日志”可切换到日志视图。日志读取在后台执行，读取期间会显示加载状态并避免重复刷新；日志只保留近期内容。可在运行日志页面刷新，按需复制或检查诊断信息。

![运行日志](screenshots/07-运行日志.png)

## 7. 常见问题

**文件没有出现在列表中**  
确认资料夹已添加并完成索引；检查目录访问权限和网络共享连接，然后重新扫描。

**搜索不到刚添加或修改的文件**  
等待索引任务完成后再搜索。若索引状态异常，可重新扫描；需要彻底重建时使用“完整重建索引”。

**OCR 暂不可用**  
在 OCR 页面查看引擎状态。RapidOCR/PaddleOCR 的应用管理运行环境可能需要首次准备；检查网络、磁盘空间和安装状态后重试。

**启动或日志加载时间较长**  
初始化和日志读取在后台运行，窗口会显示加载状态。可先查看运行日志中的错误，再重启程序。

**更新已下载但版本未变化**  
后台下载不会自动安装。保存工作后，在设置的更新区域点击“重启并安装”。

## 数据与隐私

本地索引、RapidOCR、Windows OCR 和 PaddleOCR 在本机运行，PDF 保留在原目录。配置 MinerU 外部 OCR 服务时，所选文件会发送到配置的服务端点。可选查询扩展向模型发送查询词，不发送 PDF 内容。数据库位于应用数据目录。
